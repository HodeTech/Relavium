## Unit 2 — registry, palette, defects and first-run basics (2026-11-24)

**Commits.** `d19b9364` one record of overlay flags (2.1); `425d5713` one command table that orders the palette, and no shell command in the TUI's remedies (2.2 and 2.3); `dd5fe5f9` a keyless first run that keeps what was typed (2.4); `b2103932` the findings of the first review round; the clean-up commit that follows it.

**What it delivered.**

- **One record of overlay flags** (`render/tui/overlay-flags.ts`): 14 flags and a table of the gates each closes; the keyboard-ownership lists that were written out by hand in a dozen places (the Home's screen slot, the paste flags, the wheel gate, the interrupt context, the strip pause, the prompt-hidden gates, three custody predicates) derive from it; the nine places where the old lists disagreed are preserved row by row and pinned. A popup will be one more flag.
- **One command table** (`commands/repl-commands.ts`): one definition per name with placements for the Home, a chat and the Home-hosted chat (group, rank, per-surface description, surface class, availability); the palettes are built from it once per state change. `/` then `Enter` never leaves the application (it ran `/exit`: exit code 0); the first enabled row is the default; `/exit` is the last row of every list; `/clear` and `/resume` are dim with their reasons; arrows skip dim rows; `/help` joins both palettes; a keyless Home leads with `/providers`; a chat's list opens above the prompt with its first row beside it; a command typed where it is not offered answers one line naming the surface that has it.
- **No shell command in the TUI's remedies**: about forty strings, three wrong remedies, the stand-alone `/clear` pointer; a pattern test over the syntax tree of the TUI-reachable sources with a short reasoned allow-list.
- **A keyless first run** in the existing cards: the draft is kept and unsent; a key-shaped draft is never kept or recorded; a failed build shows its whole failure in the wrapping notice area and restores the draft; the skip says so; `Retry the check` first on a network failure and `Save it anyway` never pre-selected; no key prompt with the keychain down; one spelling of the labels, display names; the keyless line and hints; the cursor visible without colour; the first-run offer waits below 80×24.

**Review round 1** (five fresh agents: correctness, a security sitting on opus, the rebuilt CLI re-observed in the sandbox, test quality and pins, architecture and performance). No blocker. Fixed in `b2103932`: the key prompt reachable with the keychain down by three routes; the consent card opening on `Use it` under a chained `Enter` (now `Not now` until Step 6 adds the input guards); a key-shaped draft recorded in the history on the keyed path; a 'looks like a key' predicate that was the whole diagnostic scrubber (discarded `Explain Basic auth`, missed a key after a word character); a slash-led key echoed as `Unknown command`; an unbounded failed-build notice; a short query highlighting `/exit`; a stand-alone remedy that said 'restart' when another provider was usable; Home-chat remedies naming `/providers`; the model picker saying 'default' for a reseat; no cursor under `--no-color`; a stand-alone `/resume` answering 'unknown command'; the `'tui'` notice wording hard-wired into the scripted `agent run` and plain chats; hollow tests (a pasted slash line, a dim-row oracle); the `usage-coverage-controls` permanent workload pin (583). The observed screens of the rebuilt CLI are the evidence; they are not a substitute for the real-terminal rows still owed.

**Review round 2** (five new agents: independent correctness walk, a second opus security sitting that attacked the round-1 fixes, the final build observed again in the sandbox, test quality with 113 mutants against the new tests, and maintainability with a check of the step's own claims). No blocker. The observation confirmed every round-1 fix on the real build (the palette's group gaps are all-or-none, the consent card opens on `Not now` and 100 ms of held `Enter` wrote nothing, no route reaches a key prompt with the keychain down, a key-shaped draft leaves no trace on disk, the cursor shows under `NO_COLOR`, `--no-color` and `FORCE_COLOR=0`). Fixed in the commit that follows `addfd91f`: `/doctor` in a plain or `--json` chat printed the TUI wording; a hosted `/run` showed shell commands inside the run view (the surface is now a required field of the run core, the shell paths pass `'shell'` and the Home's host `'tui'`); typed arguments in a chat's palette were dropped (`/doctor --deep`, a Home-only word) and now go through the chat's own dispatch; a key-shaped draft on a keyed Home was still sent and written to the transcript (now refused like the keyless one); the short-query rule fell back to an ending row when only a description matched (`/rel` ran `/exit`, `/res` ran `/clear`: no row of `clear`, `cancel`, `compact`, `exit` or `trim` is highlighted unless the query starts its name, and the typed line is dispatched instead); the key-shape predicate now folds compatibility forms and strips default-ignorable and combining characters, adds `sk-None-`, `sk-or-v1-`, `gsk_`, `xai-` and a generic `sk-<word>-` rule, and drops word-boundary dodges and a few false positives; a slash-led key is no longer echoed in a chat; the deferred first-run offer is spent after any provider run; complexity of five functions brought under 15; and the tests that the mutation check found weak. Counts: 741 test files, 15,504 tests.

**Human text that changed on non-TTY paths in this unit** (no `--json`, NDJSON or exit code changed; recorded because the commit messages said 'unchanged'): the `warning:` lines of `relavium run`, `gate`, `agent run` and plain chats spell `--input-price` and `--output-price` where they spelled the deprecated `--input` and `--output`; the shell `--help` footer reads `NO_COLOR (non-empty ⇒ off)`; plain, `--json` and one-shot `/help` and the unknown-slash hint follow the registry's new order, with two description rewordings (`/mode`, `/doctor`); the `chat-export` remedy and the `relavium chat --agent <ref>` remedy in two scripted error texts were replaced by wording that names no shell command; the plain driver keeps the `/export` hint (`run it with relavium run <id>`) that the TUI drops.

**Accepted limits recorded by the reviews**: a key split by whitespace inside its first twenty characters is not recognised (joining whitespace would turn `task - management…` into a key); a prefix-less 40-character key is not recognised; a keychain whose `get` works and whose `set` fails still validates a typed key and then says honestly that it was not saved (G19 residual; it cannot be gated); `TERM=dumb` shows no prompt cursor; a hosted resume of a run with masked secrets and no secret port would show the `secretPipeHint` shell pipe in the TUI (one string, left for the flows unit); the surface vocabularies (`NoticeSurface`, `CredentialSurface`, `ClearedNoticeSurface`, `SetupSurface`, `PaletteSurface`, `CommandListSurface`) are seven parallel unions with ad hoc mapping and want one `Surface` type in the language unit; the Home controller is one closure of about 3,300 lines and 14 of the 22 fields of its REPL context are inert (the `ReplCommandContext` shape does not fit the Home).
