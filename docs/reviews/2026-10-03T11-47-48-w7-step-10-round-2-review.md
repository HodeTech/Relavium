## Findings and corrections

### R2-1 — High: a terminal media sweep could outrun its conservative money write

After paid media admission, a refused passive effect check settled the outstanding job.
If current pricing disappeared, threw or became unsafe, the engine queued the accepted
conservative E but persisted its terminal before that queued commitment was acknowledged.
The commitment then lost compare-and-append ordering. Known pricing was a positive control;
three fault modes reproduced missing durable money. The reviewer reproduced the same defect
in the actual pre-Step-10 foundation, so this is an inherited correction.

[Engine settlement](../../packages/core/src/engine/engine.ts) now joins money durability
after cleanup and before terminal sequencing/totals. Write faults retain the existing safe
failure policy, cancellation retains its cause, and takeover prevents stale terminal output
or successor-lease release. Settlement stops heartbeat immediately; terminal lease cleanup
occurs after persistence and before delivery, so draining the stream observes completed
cleanup. Reclaiming ownership for settlement does not arm a new heartbeat.

Eight [permanent actual-runner controls](../../packages/core/src/engine/budget-authorization-live.test.ts)
cover known/unpriced/throwing/unsafe pricing, held acknowledgement, write fault, takeover
and reentrant pricing cancellation. They assert raw durable ordering, conservative versus
actual totals, safe terminal causes, no resumed egress and zero owned timers. Existing
lease/liveness assertions remain unchanged. Dated notes in
[ADR-0077](../decisions/0077-realized-cost-ledger-uses-the-conservative-commitment-barrier.md)
and [ADR-0079](../decisions/0079-cross-process-run-ownership-lease-and-fencing-token.md)
record the repairs without changing the accepted decisions.

### R2-2 — High: a legal historical input decision aborted interrupted-run discovery

The immutable actual predecessor can emit a budget `human_gate:resumed` with
`decision: input_provided` and payload. ADR-0097 requires treating that historical outcome
as rejection. The current reducer instead called it corruption; one such run could abort
aggregate interrupted-run discovery and hide an unrelated resumable human gate.

The [one suspension reducer](../../packages/shared/src/run-suspension.ts) now normalizes
only historical budget input with no native authoritative pause/decision, frozen allowance
or approved amount. It records fatal rejection and creates neither allowance nor output.
Native input decisions and frozen authorization corruption remain refused. Original
persisted rows and payload bytes remain unchanged.

Permanent Shared, checkpoint, reference-store and SQLite controls cover both identified
and historical missing-ID decisions, unrelated interrupted siblings and strict native
negative controls. The [offline compatibility producer](../../tools/budget-replay-compat/legacy-producer.mjs)
now emits an actual predecessor input decision, cuts its six-row durable prefix without
rewriting rows, and passes it through current checkpoint, reference discovery, SQLite
strict replay/discovery and admitted resume. All four current checks pass with zero
provider resolution, credentials, provider calls, fetches or tool dispatches.
[ADR-0097](../decisions/0097-a-budget-approval-is-an-allowance-not-an-exemption.md) records
this implementation correction to its existing historical-input rule.

### R2-3 — Medium: a late authority did not check a companion's amount

Authority-first replay rejected a conflicting companion amount, but companion-first replay
checked only decision and actor when authority arrived. The parent reproduced the
asymmetry with both native and legacy decisions. No overspend was demonstrated; the
honest producer writes authority first.

One pure comparison now checks decision, actor, payload and any supplied approved amount
in both orders. Eight permanent Shared controls cover matching/conflicting amounts,
native/legacy authority and both orders. The canonical
[event contract](../reference/contracts/sse-event-schema.md) and dated
[ADR-0100 note](../decisions/0100-budget-authorization-is-durable-state-with-a-replay-barrier.md)
state the same symmetric rule.

### R2-4 — Medium: runtime redirection between two pinned roots escaped the fence

The first-round fence rejected unlisted files and byte drift, but after preflight an
issuer's dependency could be redirected to another already-pinned version. The real SDK
SSE class loaded the wrong pinned `content-type` root while all portable bytes still
matched. This invalidated dependency-closure assurance; it did not demonstrate a billing
or protocol bypass. The canonical protocol fixture does not instantiate that SDK transport.

The [runtime fence](../../tools/budget-replay-compat/dependency-runtime.mjs) now rechecks
issuer dependency/peer/optional edges, including newly present optional dependencies,
and binds both CJS and ESM resolution to the captured target root. Worker root imports
are explicit. Relative, import-map and file-URL paths cannot cross package ownership;
the existing captured native SQLite exception remains explicit. File bytes are still
checked independently. The immutable predecessor source and dependency archive are unchanged.

Thirteen [permanent graph/runtime controls](../../tools/budget-replay-compat/closure-smoke.mjs)
include pinned-to-pinned CJS/peer/ESM changes, optional appearance and unauthorized root
imports. The ESM graph fixture uses an inert TypeScript stand-in, disclosed in the
[tool README](../../tools/budget-replay-compat/README.md); real predecessor protocol workers
still load the archived TypeScript sources. The parent's separate real SDK class control
passes unchanged and refuses the redirected edge before class load, with portable bytes
and the restored literal link independently verified.
