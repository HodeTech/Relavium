## Findings and corrections

### R1-1 — High: predecessor dependencies were byte-pinned but their runtime edges were not

The [compatibility check](../../tools/budget-replay-compat/check.mjs) verified the 93
listed package roots and 9,240 portable files, then linked installed directories.
Nested dependency, peer and optional resolution was not bound; the loader admitted any
`node_modules` path, and CommonJS resolution bypassed its ESM fence.

The reviewer and parent independently copied the actual tool, source and packages into
owned fixtures. The unchanged control passed twelve real prefix refusals and two legacy
controls. Redirecting only SQLite's owned `bindings` edge loaded an unpinned module while
every listed package/file hash still passed. This was a false integrity pass, rather than
a demonstrated allowance or billing bypass. An initial portable fixture omitted Drizzle's
peer fallback and failed before drift; the corrected self-contained controls reproduced
the finding independently. That setup failure is preserved and is not a product finding.

The [closure verifier](../../tools/budget-replay-compat/dependency-closure.mjs) now binds
all installed declared dependency/peer/optional edges to exact package roots before a
worker starts. The extended manifest contains 180 roots, 12,000 portable files and 296
edges: two builtins and 29 absent optional edges are explicit. Every version exists in the
unchanged archived predecessor lockfile; the original 93 roots' portable bytes remain
identical. Duplicate versions have separate identities. Manifest fields are portable,
without the prior unused absolute producer paths.

Workers use physical owned package copies with reconstructed exact edges, checked again
after copying. The [runtime fence](../../tools/budget-replay-compat/dependency-runtime.mjs)
and [loader](../../tools/budget-replay-compat/loader.mjs) check resolved files against the
captured byte inventory, including CommonJS calls in the loader thread. Worker tools are
captured too; neither an arbitrary external path nor an arbitrary owned file is enough.
The existing native SQLite build exception is explicit: its source/version stay pinned,
and its copied binary is hashed for that invocation. No dependency is installed or added,
and unrelated current-lock evolution remains permitted.

Seven [permanent guard controls](../../tools/budget-replay-compat/closure-smoke.mjs) cover
redirected CJS/peer edges, newly resolving optionals, unlisted files, post-preflight runtime
resolution/byte drift and a positive graph with two versions plus its required peer.
The parent adapted the original actual-predecessor intervention to the corrected manifest:
control exits 0; edge drift exits 1 before a protocol worker starts, with all 180 roots and
12,000 portable files unchanged and no marker loaded. Removing only the owned runtime
CommonJS fence makes its negative guard fail and the inert marker execute; restored bytes
are verified. The source archive and its original manifest are unchanged.

### R1-2 — High: passive resume could activate media after its acquired lease expired

The [resume facade](../../packages/core/src/engine/engine.ts) acquired ownership before
strict replay but waited through passive admission without renewing it. It then adopted
the original fence without revalidation. A successor could take over during a slow effect
preflight; the old media-only resume or resolved-budget-gate kick still read a credential
and polled once before its later write fenced out. No new submission, accepted stale write
or old terminal was demonstrated; the successor's lease survived.

Independent actual-runner fixtures use native emitted histories, enforcing reference
store/lease ports, offline providers and an injected lease clock. The parent repeated both
the current failure and exact pre-Step-10 causal control. The predecessor foundation
heartbeated during preflight and prevented takeover. A new quoted decision was separately
safe because its authoritative write fenced before credentials; it was not conflated with
the media kick. Seven successful-sibling acknowledgement races also passed.

The facade now atomically renews the exact acquired owner/generation after every passive
await and before registration, adoption or activation. Refused admission settlement takes
the same barrier. It does not acquire another generation. A takeover or unconfirmable
claim refuses transiently with safe `run_owned_elsewhere`; cleanup releases only the old
fence. A cleanup fault leaves its bounded TTL and does not expose private host text.
An expired claim without a successor renews and completes normally.

Ten new [actual-runner controls](../../packages/core/src/engine/budget-authorization-live.test.ts)
cover both kicks, real TTL takeover, expiry without takeover, same-fence renewal, slow
effect refusal and heartbeat/release faults. The complete permanent suite passes 70/70
in a parent-owned source-bound replay. Removing only the renewal barrier produces nine
intended failures and 61 passing controls; the fixed bytes are restored exactly. A separate
three-case standalone prototype passes, and its guard removal reintroduces the stale-owner
failure. The [canonical resume contract](../reference/shared-core/agent-runner.md) and dated
[ADR-0079 correction](../decisions/0079-cross-process-run-ownership-lease-and-fencing-token.md#implementation-correction--2026-10-03)
record this implementation repair.
