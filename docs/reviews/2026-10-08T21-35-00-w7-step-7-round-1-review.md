## Verified findings and corrections

**High — a raced confirming read loses already observed terminal usage.** The grammar
owns the first valid terminal quantities, but a caller abort or attempt deadline replaces
the chain diagnostic before the terminal is returned. Parent independently reproduces
stop/error across EOF, cancellation and deadline: EOF folds once, while both races fold
zero times despite the observed usage. The verifier now transfers its validated, owned
usage into assignment-only attempt-local state before the confirming read. The existing
single settlement path attaches that observation to the raced diagnostic and folds once.
There is no accounting callback or fabricated clean stop in the verifier.

Twenty-four permanent controls cover stop/error, the three endings, valid positive/zero
usage, invalid usage and pricing failure. They verify immutable first quantities, exactly
one accounting observation, late source completion, and no private diagnostic disclosure.
Removing only the transfer fails twelve of the twenty-four tests; exact restoration passes.

**High — Anthropic defers native overflow authority until SDK EOF.** Later vendor deltas
can rewrite usage or turn the native failure into success; a later SDK error can advance
the chain, and an open body can lose all observed usage. Parent reproduces these outcomes
through the actual installed SDK with injected offline responses. The adapter now yields
the first native failure and its final usage immediately, then returns from its iterator.
Later content, stops and secondary teardown errors cannot replace that observation.

Twenty additional actual-SDK controls cover five tails with/without derived content,
immediate/held/throwing body cleanup across ordinary/cancel/deadline endings, and a fresh
second response after a legitimate pre-content timeout. Cleanup acknowledgement is joined
in the test before checking for duplicate accounting. Removing the immediate native handoff
fails all ten tail controls. The restored five-suite LLM selection passes 256 tests.

**High — legitimate fractional native duration loses realized accounting.** The independent
preflight and Parent's actual-source/native-SQLite reproduction verify that authored
`12.5` seconds at 201 micro-cents/second is forced through integer-only provider `Usage`.
Successful synchronous generation and parked done/failed/deadline/cancel settlement retain
the estimate instead of recording the actual charge. The helper now uses the existing
rate-only `estimateMediaCost` kernel. It rounds once to 2513 micro-cents, retains the safe
integer image-count guard and narrow unknown-model catch, and leaves canonical `Usage`
validation unchanged. Both native settlement paths share this correction.

Thirty-four runner/engine controls and five actual-SQLite controls pass. The latter use
real migrations, history and lease ports: one cost row, SQL `SUM(run_costs)` and the run
total each equal 2513. The offline synchronous TTS case uses the actual OpenAI adapter;
its wire intentionally omits authored duration, so this proves request-volume accounting,
not measured provider duration or invoicing. Restoring the old pricing route through a
temporary source transform fails 27/39 controls, including every SQLite case. A broader
266-test selection and 43 existing engine-media cases pass separately.
