**R5-1 — High, inherited: a waiting-only parallel budget park retained a renewable lease.**
Two agent budget gates, with or without an ordinary human sibling, could emit aggregate pause
before the last durable companion acknowledgement. The later append reclaimed generation 2.
Duplicate aggregate suppression then left that claim's heartbeat running while every node
waited on a human decision, refusing a fresh distinct owner's resume. Actual SQLite reproduces
this on both current and actual pre-Step-10 source. Four genuine liveness callback invocations
at advanced store times continuously renewed the claim; this is not a real elapsed-time or
separate-process measurement. After the old process stops renewing, normal TTL expiry remains.

The parent independently reproduced the race with the actual CLI assembler, engine and SQLite.
Its correction waits for **all in-flight pause publications**, including each authority and
companion, before aggregate pause hands the lease back. An ordinary gate already claimed by
a decision also remains visible while its payload is pinned, until its vertex can complete:
the tighter pause ordering exposed an immediate-decision scheduler race in an existing effect
resume control. Claimed pending gates retain ownership until their decision work finishes. Two delayed media
success/failure regressions cover that adjacent transition and assert no aggregate handoff
while the actual media pin is held.
Media polling retains its existing lease. The [canonical resume contract](../reference/shared-core/agent-runner.md),
engine architecture and dated [ADR-0079](../decisions/0079-cross-process-run-ownership-lease-and-fencing-token.md)
and [ADR-0100](../decisions/0100-budget-authorization-is-durable-state-with-a-replay-barrier.md)
corrections describe the result. No timeout, clock, generation, host-port or approval policy changes.

**Scoped asynchronous host observation.** A successful final renewal ACK held beyond its TTL
can arrive after a successor acquires. Actual current and pre-Step-10 source expose an equivalent
last-await freshness window, shifted from acquire to renewal. The observed extra operation is
one authenticated status poll for an already submitted media job; there is no second paid
submission, accepted stale write, old-owner terminal or successor deletion. Liveness or cancel
before the work callback prevents it. The shipping SQLite lease operation is synchronous.
Adding another final renewal only moves the last ACK boundary; it is not a universal cure.
The canonical contract now states this limit explicitly, retaining the accepted store-side clock,
TTL and fences without inventing an asynchronous freshness policy. This is not counted as a
new shipping SQLite regression or hidden as a passing zero-I/O oracle.
