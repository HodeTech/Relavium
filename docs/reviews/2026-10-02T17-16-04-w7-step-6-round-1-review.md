## Findings and corrections

1. **High — opaque cap values defeated the snapshot.** Schema-valid boxed numbers and native
   `toJSON` objects established no numeric reservation, while SDK JSON emitted a valid large cap.
   Changing a closure during key resolution changed the wire without changing object identity.
   [Cap lowering](../../packages/llm/src/output-cap.ts) now captures surviving JSON values once
   under their original property key, deeply freezes them and uses the same data for pricing and
   wire. Private original identities bind measured plans without executing caller code again.
   Discarded opaque controls are not serialized; ordinary invalid JSON shapes remain invalid data.
2. **High — an outer serializer replaced the mapped body.** A callable native `toJSON` reserved
   canonical 17 tokens but sent 200,000. Shared reconciliation now filters this executable body
   rewrite while preserving noncallable data bearing that name. This enforces accepted mapped-cap
   authority; the append-only [ADR-0101 correction](../decisions/0101-configured-output-estimates-apply-only-when-the-wire-is-uncapped.md#implementation-correction--2026-10-02-w7-step-6-first-review)
   records the finding without introducing another generation control.
3. **High — ambient SDK routes contradicted official evidence.** OpenAI, Anthropic and Gemini
   environment overrides sent mocked requests to another host while the hook/record remained
   official. The new official-only refund therefore released an uncertain custom refusal.
   Official factories now pin their intended SDK endpoint; Gemini also pins its backend.
   Validated explicit custom factories retain their existing classification and wire semantics.
4. **High — a stream observer could impersonate provider retry policy.** An observer throwing
   429 on an original fatal 400 caused two provider calls and three observations. All failure
   exits now invoke observers outside provider normalization, including credential-time cancel
   and deadline exits on both paths. Consumer exceptions propagate once; they cannot create
   another attempt or replace provider facts.
5. **Medium — combined rounding under-reserved one microcent.** Three input/output tokens at
   valid fractional rates estimated 123 while realized cost charged 124. The
   [rate-only estimator](../../packages/llm/src/budget-estimator.ts) now rounds each token class
   separately before summing and retains its arithmetic validation.
6. **Canonical-contract blocker.** The runner still promised an always-pass loop-level hook and
   future per-attempt gating; the workflow contract retained its output-only projection.
   The [runner contract](../reference/shared-core/agent-runner.md#pre-egress-injection-contract)
   now owns the required core hook and the
   [workflow contract](../reference/contracts/workflow-yaml-spec.md#resource-governance-specbudget)
   describes current input/output/media estimates, live reservations and retained commitments.
   The LLM seam links to the core hook instead of duplicating it. Later step 8/9 consumers remain
   explicitly staged.
7. **Acceptance-coverage blocker.** Permanent nondefault forwarding assertions were missing on
   several CLI entry points, and the wire matrix omitted reversed native envelopes and thinking
   separation. New tests cover fresh/resumed/reseated/cleared chat, Home fresh/clear/reseat,
   one-shot agent, gate resume, shared session/governor construction, the actual engine builder
   and direct runner/context precedence. Actual adapter tests cover both paths and native-key
   orders on official/custom OpenAI-compatible routes, official DeepSeek modern-only data and
