a priced model's missing media rate, then inserted its allow/warn reservation. A host's
`onUnpriced` callback could re-enter admission synchronously in that window. Two calls then
held 600 microcents each under a 1,000-microcent cap. The ordinary sequential control refused
the second call. This establishes a public callback-boundary defect; no reviewer claimed the
current passive CLI renderer re-enters admission.

`15709ce5` governor comparison. Both admitted 1,200 under 1,000. The parent compared the saved
baseline bytes to git and verified that only the runtime LLM import was rebound to current
compiled helpers; this is source-level baseline evidence, not a frozen predecessor binary
closure. The parent's replay of the financial reviewer's separate two-case probe also failed
the desired non-overbooking assertion and passed its sequential control.

Allow/warn reservations now enter the global ledger immediately after evaluation, before any
host notice or warning write. Refused fail/pause calls retain their notice without a reservation.
Warning calls still await the shared durable write and release their admissions if it fails.
One canonical [hook contract](../reference/shared-core/agent-runner.md#pre-egress-injection-contract)
and an append-only [ADR-0028 correction](../decisions/0028-workflow-resource-governance.md#implementation-correction--2026-10-02-w7-step-6-fifth-review)
describe the enforcement change; no new policy, dependency, public signature or approval unit
