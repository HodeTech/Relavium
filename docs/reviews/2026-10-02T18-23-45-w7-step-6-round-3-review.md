## Finding and correction

**High — deeply frozen JSON retained inherited executable serialization.**
[Cap capture](../../packages/llm/src/output-cap.ts) parsed records and arrays, then froze their own
state. Their mutable prototypes could still supply `toJSON`. A key-sensitive inherited serializer
activated during credential resolution turned captured nonnumeric cap data into numeric 200,000,
while admission reserved configured fallback 17. Both installing a property after capture and
changing a pre-existing serializer's closure reproduced the mismatch without changing plan identity.

The wire reviewer used the installed SDKs' actual HTTP JSON on generate and stream: official
OpenAI's two native keys, direct custom OpenAI's two keys, official DeepSeek's legacy key and
Gemini's native key, with object and array shapes. Its 72-case matrix produced 48 desired-behaviour
failures and 24 ordinary-shape controls. The financial reviewer separately reproduced cap 100
admitting 35 microcents, followed by actual OpenAI HTTP cap 200,000, worth 400,001 at the same
synthetic rates. These describe the same shared defect, not two findings or measured provider charges.

The capture now recursively detaches every parsed object's and array's prototype before freezing.
Array identity, own data keys and JSON shape remain intact. Inherited serialization cannot reopen
the admitted snapshot. Permanent [actual-SDK tests](../../packages/llm/src/adapters/output-cap-prototype-wire.test.ts)
retain both serializer variants and ordinary controls on both paths and all six routing/key pairs.
Unit tests also pin nested isolation, ordinary `toJSON`/`__proto__` data, array identity and caller ownership.
The canonical [seam contract](../reference/shared-core/llm-provider-seam.md#current-request-estimates-and-bound-output-caps)
and a dated ADR-0101 note explain the existing immutable-projection obligation.

This requires ambient prototype behavior in the trusted process; it is neither a YAML exploit nor
a claim that arbitrary host-wide mutation is sandboxed. The correction adds no generation control,
runtime dependency or second lowering authority. Invalid native JSON retains its shape; synthetic
success responses do not certify that a provider accepts that invalid shape.
